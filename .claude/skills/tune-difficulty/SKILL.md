# Tune Difficulty

1. jin의 플레이 관찰을 "예상 / 실제 / 재현" 으로 정리한다. 무엇이 어렵거나 쉬운지 한 문장.
2. 수치는 Assets/Scripts/Core/GameConfig.cs 에서만 바꾼다. 한 번에 수치 하나(많아야 둘).
3. 바꾸기 전에 난이도 실험실(docs/game-concept.md의 링크)에서 같은 값으로 승률이 어떻게 변하는지 먼저 본다.
4. 둔갑 시간을 줄였다면 하루 최소 박자(25/20/21)보다 작아지지 않는지 확인한다.
5. 테스트 중 수치에 묶인 것(DisguiseBeats 28/30/32, 첫 밤 허기 50 등)이 깨지면, 테스트를 지우지 말고 새 기대값으로 고치고 이유를 커밋 메시지에 적는다.
6. prototype-check 스킬로 점검한 뒤, progress.md에 "바꾼 수치: 전 → 후, 이유" 를 남긴다.
