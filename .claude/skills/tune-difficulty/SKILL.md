# Tune Difficulty

1. jin의 플레이 관찰을 "예상 / 실제 / 재현" 으로 정리한다. 무엇이 어렵거나 쉬운지 한 문장.
2. 수치는 Assets/Scripts/Core/GameConfig.cs 에서만 바꾼다. 한 번에 수치 하나(많아야 둘).
3. 바꾸기 전에 기획서 4장의 근거(docs/game-concept.md의 링크)를 먼저 읽고, 고양이 길이나 지도를 바꿨다면 안전한 끝(12/18/21)을 테스트로 다시 구한다.
4. 낮 걸음을 줄였다면 의심 0으로 깰 수 있는 최소 걸음(21)보다 작아지지 않는지 확인한다. 밤 걸음은 가장 안전한 길(21걸음)보다 작아지지 않아야 한다.
5. 테스트 중 수치에 묶인 것(NightBonus 12→3 · 18→1 · 21→0, 안전한 끝 12/18/21 등)이 깨지면, 테스트를 지우지 말고 새 기대값으로 고치고 이유를 커밋 메시지에 적는다.
6. prototype-check 스킬로 점검한 뒤, progress.md에 "바꾼 수치: 전 → 후, 이유" 를 남긴다.
