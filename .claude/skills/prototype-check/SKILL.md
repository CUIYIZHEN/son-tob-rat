# Prototype Check

1. 무엇을 바꿨는지와 확인할 동작을 한 줄로 적는다.
2. 컴파일: Core와 Game 코드에 새 오류가 없는지 본다 (Unity Console, 또는 PR의 CI 로그).
3. 규칙 테스트: Assets/Tests/EditMode 전체 실행. 바뀐 규칙에는 테스트를 하나 더한다.
4. 지도를 고쳤다면 메뉴 `손톱 쥐 → 걸음 길 L 재기`로 세 사람 모두 L=30인지 본다.
5. PR의 CI(EditMode tests, WebGL build)가 초록인지 본다.
6. 아래 형식으로 보고한다. 확인하지 못한 것은 통과로 쓰지 않는다.

## 보고 형식
- 바꾼 것:
- 통과: (테스트 수, 빌드)
- 실패: (원문 오류 메시지)
- 확인 못 함: (예: 휴대폰 직접 플레이) 와 이유
- 직접 플레이로 볼 것: 예상 / 실제 / 재현 절차 형식의 체크 항목 2~3개

마치면 progress.md의 네 칸(완성 · 확인 · 확인 못 함 · 남은 문제)을 고친다.
