# 손톱 먹은 쥐: 기획 요약

자세한 기획서: 「손톱 먹은 쥐 — 프로토타입 기획서」 (Claude Doc) https://claude.ai/artifact/K9TLDRVtaGcMpYCH4pft13
범위는 밤 1번과 낮 1번이다.

## 만들 경험
들킬 듯 말 듯한 긴장 속에서, 고양이 눈이 지나가는 길을 읽고 파고드는 타이밍 퍼즐.

## 규칙
1. 밤: 쥐가 되어 어둠 속에서 고양이 눈(붉은 칸)을 피해 늘 같은 칸(7, 10)의 도령 손톱을 먹는다. 쥐는 바라보는 방향 앞 3칸만 보인다.
2. 낮: 도령으로 둔갑해 남은 걸음 안에 임무 3개(서당 · 정자 · 장승)를 끝낸다.
3. 모든 행동(걷기, 두 칸 달리기, 기다리기, 먹기, 임무하기)은 1걸음이고, 사람과 고양이도 한 칸씩 움직인다.
4. 눈에 든 칸을 달리면 의심 +30, 진짜 도령과 마주치면 걸어도 +40. 의심이 100이 되거나 걸음이 다하면 낮 실패.
5. 밤에 고양이 눈에 들거나 해가 뜰 때까지 못 먹으면 밤을 처음부터 다시 한다.

## 수치 (GameConfig.cs)
| 수치 | 값 | 근거 |
|---|---|---|
| 밤 걸음 | 24 | 가장 안전한 길이 21걸음, 여유 3 |
| 낮 시작 걸음 | 26 | 의심 0으로 깰 최소 21걸음 + 여유 5 |
| 밤 보너스 | min(3, ⌊(24 − 먹은 걸음) ÷ 4⌋) | 12걸음(최적)이 +3, 21걸음(곧장 기다렸다 가기)이 +0 |
| 시야 | 3칸 | 사람 · 고양이 · 쥐가 같다 |
| 의심 | +30 / +40, 100에서 실패 | 처음 하는 사람은 평균 두 번쯤 들킨다 |

## 밤 길 (테스트로 확인)
- 쉬지 않고 곧장 가면 7걸음에 잡힌다
- 12걸음 기다렸다 걸으면 21걸음에 먹는다 (+0)
- 걷기만으로 가장 빠르게 먹으면 18걸음 (+1)
- 달리기까지 쓰면 가장 빠르게 12걸음 (+3)

## 확인되지 않은 것
- 낮 승률과 의심 평균은 실제 플레이로 재지 않았다. 4와 3(보너스 식)은 플레이 뒤에 가장 먼저 다시 본다.
